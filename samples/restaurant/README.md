# 博多もつ鍋 かざぐるま（多言語サイトのサンプル）

日本語・English・한국어・简体中文の4言語に切り替えられる、飲食店の1ページサイトです（架空の店舗）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体。翻訳する文章には `data-i18n="キー"` を付けています |
| `i18n.js` | 翻訳データ（4言語）と、お品書き・コースのデータ |
| `script.js` | 言語の切り替え、お品書きの表示、タブ、メニュー |
| `style.css` | スタイル |

## 言語の切り替え

- ヘッダーの「言語」ボタンから選びます。選んだ言語はブラウザ（localStorage）に保存され、次に開いたときもその言語で表示されます。保存できない環境でも、表示の切り替えはできます。
- 初めて開いたときは、ブラウザの言語設定に合わせて表示します（対応していない言語なら日本語）。
- 切り替えると、HTML の `lang` 属性、ページのタイトル、説明文（description）も変わります。

## 文章を直す・言語を増やすとき

- 文章の修正：`i18n.js` の該当するキーを書き換えます。
- 言語の追加：`LANGS` に1行足し、`I18N` に同じキーの訳を追加します。お品書きは `MENU` の `name` と `desc` に訳を追加します。

## 翻訳について

**翻訳はネイティブスピーカーによる確認を推奨します。** 実際のお店で使う場合は、メニュー名や料理の説明、アレルギー表示を、各言語のネイティブスピーカーに確認してもらってください。
