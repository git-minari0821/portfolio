# 画像の出典

## 使用中の画像

現在、写真はすべてプレースホルダー（「Photo」と表示される枠）です。外部の画像は使っていません。
ロゴ・唐辛子マーク・アイコンはすべて CSS とインライン SVG で自作しています（AI生成画像は使っていません）。

## 差し替える写真

`images/` に次の名前で写真を置くと、自動でプレースホルダーと入れ替わります。

- hero.jpg（ファーストビュー：もつ鍋）
- counter.jpg / table.jpg / zashiki.jpg / nabe.jpg（店内の様子）
- map.jpg（地図。実際のサイトでは Google マップの埋め込みに置き換え）
- ogp.jpg（SNSでシェアされたときの画像・1200×630）
