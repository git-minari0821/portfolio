# 画像の出典

## 使用中の画像

現在、写真はすべてプレースホルダー（「Photo」と表示される枠）です。外部の画像は使っていません。
ロゴ・アイコン・図はすべて CSS とインライン SVG で自作しています（AI生成画像は使っていません）。

## 差し替える写真

`images/` に次の名前で写真を置くと、自動でプレースホルダーと入れ替わります。

- hero.jpg（トップのメインビジュアル：施工後のリビング）
- service-water.jpg / service-exterior.jpg / service-interior.jpg（サービス紹介）
- work-1-before.jpg 〜 work-9-before.jpg、work-1-after.jpg 〜 work-9-after.jpg（施工事例の施工前・施工後。番号は js/data.js の WORKS の順番）
- president.jpg（代表あいさつ）
- map.jpg（アクセスの地図。実際のサイトでは Google マップの埋め込みに置き換え）
- ogp.jpg（SNSでシェアされたときの画像・1200×630）
